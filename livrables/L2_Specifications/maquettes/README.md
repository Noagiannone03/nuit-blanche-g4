## Ouvrir dans Figma

1. Ouvrir un fichier Figma (ou en créer un).
2. **Glisser-déposer** les fichiers `.svg` dans la page (ou *Menu → Fichier → Placer une image*).
3. Chaque planche devient un groupe : titre, repères numérotés et annotations sont des **calques texte et formes modifiables** ; la capture du jeu est une image.

Pour que les titres s'affichent avec la bonne police, installer **Permanent Marker** et **Nunito** (Google Fonts) ; sinon Figma propose une police de remplacement.

Les captures viennent du jeu réel (version du 3 novembre). Pour les refaire après une modification du jeu, relancer une partie et prendre les mêmes écrans.
